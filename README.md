# ESP32 ม.4 · เครื่องให้อาหารแมวอัตโนมัติ

ฉบับแยกจาก ESP32 Interactive Classroom เดิม เด็กเริ่มจากลองจ่ายอาหารหนึ่งมื้อ แล้วนำไฟแดง ฝา Servo เสียงเตือน และเซนเซอร์มารวมใน Lab สุดท้าย ตัวอย่างเดิมยังเปิดได้ตามหัวข้อและจากคลังวงจรใน Playground

## ลำดับกิจกรรม

1. สไลด์ 1–10 เปิดโจทย์เครื่องให้อาหาร สำรวจบอร์ด ต่อไฟแดง และทดลองสัญญาณกับ Servo
2. สไลด์ 11–16 สั่งฝาและเสียง เดิน `setup()` / `loop()` แล้วเพิ่มเงื่อนไข ตรวจ Scope และแก้ข้อผิดพลาด
3. สไลด์ 17 ฝึก Lab 1–3 บน Wokwi และทดสอบเครื่องรวมผ่านตัวจำลองในเว็บ มีโจทย์ Piezo นับเม็ดเป็นกิจกรรมเสริม

## ผังขาของโครงงาน

| อุปกรณ์ | GPIO |
|---|---|
| ปุ่มถึงมื้อ | 19 · ลง GND ตอนกด · INPUT_PULLUP |
| LED แดง | 23 ผ่านตัวต้านทาน 330 Ω ของตัวอย่าง |
| Servo | 18 · ไฟเลี้ยง 5 V ที่เหมาะกับ Servo และ GND ร่วมเมื่อใช้ของจริง |
| Passive buzzer | 25 |
| HC-SR04 | TRIG 26, ECHO 27 ที่จุดกึ่งกลางตัวแบ่ง 1 kΩ/1.8 kΩ |
| DHT22 | 32 · pull-up 10 kΩ ไป 3V3 |
| IR สะท้อนที่ชาม | 33 · Active LOW · Wokwi ใช้สวิตช์แทน OUT ของเซนเซอร์ |
| Piezo เสริม | 34 / ADC1 ผ่านวงจรปรับสัญญาณให้เหมาะกับ 3.3 V |

แบบฝึกตั้ง RH ตั้งแต่ 70% ให้พักจ่าย ค่า RH คือความชื้นอากาศในถัง ระยะ 6 ซม. และ 24 ซม. ใช้จำลองเต็มกับหมด เปอร์เซ็นต์เป็นค่าประมาณจากระยะ ส่วน IR สะท้อนใช้ตัวส่งและตัวรับในหัวเดียวกันเพื่อตรวจว่ามีตัวเข้าใกล้ชามหลังจ่าย ฝาเปิดตามเวลาใน Lab ให้เด็กแยกบทบาทนี้จากโจทย์นับเม็ดด้วย Piezo

## รันและ build

ใช้ Node.js 22.12+ จากนั้นรัน `npm install`, `npm run dev` หรือ `npm run build` ตามงาน ผล build อยู่ใน `dist/` เว็บเป็น static โค้ดสำหรับ Wokwi อยู่ใน `public/labs/lab1` ถึง `lab3` และสร้างจาก `src/classroom/labs.mjs` รวมกับสเก็ตช์ใน `src/classroom/feeder-firmware/`

`npm run check:feeder` ทดสอบเวลาและเงื่อนไขการจ่าย ไฟแดง สถานะออฟไลน์ มื้อซ้ำ IR และผังขา Lab แล้ว `npm run build` รันการตรวจเดิมของคอร์สด้วย

## แจ้งเตือนสำหรับเดโมครู

เว็บและโค้ด Wokwi เริ่มในโหมดแสดงเหตุการณ์จำลอง Lab 3 รองรับการส่งจริงจาก ESP32 เมื่อมี `teacher-secrets.h` ข้างสเก็ตช์ เริ่มจากแม่แบบใน `public/labs/teacher/teacher-secrets.example.h` แล้วกำหนด Wi-Fi 2.4 GHz, bot token, chat ID และ root CA ที่ตรวจ TLS ของ Telegram บนเครื่องครู เก็บไฟล์ที่กรอกแล้วไว้บนเครื่องและทดสอบข้อความในแชตเดโมก่อนสอน การส่งข้อความทำงานแยกจากการจับเวลาฝา

เอกสารแหล่งที่มาของคอร์สเดิมยังอยู่ใน `SOURCE-PROVENANCE.json` และ `REVERSE-ENGINEERING.md`
