ESP32 ม.4 • คาบที่ 1 สไลด์ที่ 2 / 17

หลักการทำงาน: Input → Process → Output

ตามดูว่าข้อมูลในเครื่องให้อาหารแมวเดินจากเซนเซอร์ไปถึงอุปกรณ์ที่ทำงานยังไง

สัญญาณเดินไปทางไหน?

เลือกอุปกรณ์ฝั่ง Input แล้วอ่านกติกาของ ESP32 ตรงกลาง

Input

เลือกสิ่งที่บอร์ดจะอ่าน
55% RH

Process

ESP32

เทียบกับ 70% RH และตรวจว่ามีอาหารพอ เมื่อถึงมื้อจึงเริ่มจ่าย

Output

บี๊บ → ฝาเปิดและปิด

เมื่อตรวจเงื่อนไขการจ่ายผ่าน

เลือกอุปกรณ์หรือเปลี่ยนเงื่อนไข แล้วลองเดินสัญญาณ

ดูตัวอย่างเดิมเทียบกับการทำงานของร่างกาย
1. INPUT (ตา หู ผิวหนัง)

เซนเซอร์ / ปุ่มกด

ทำหน้าที่รับรู้สิ่งรอบตัว

2. PROCESS (สมอง)

บอร์ด ESP32

คิดและตัดสินใจตามโค้ดที่เขียน

3. OUTPUT (แขน ขา ปาก)

มอเตอร์ / ไฟ / ลำโพง

แสดงผลลัพธ์ได้หลากหลายแบบ

เลือกรูปแบบ Output:
พร้อมจำลอง: กดปุ่มด้านล่างได้เลย!
