ESP32 ม.4 / THE WIRING BENCH

เลือกพิน แล้วลองต่อวงจร

ขาล่างสุดซ้ายคือ 5V ไม่ใช่ GND · เริ่มจากสิ่งที่อยากทำ หรือคลิกสำรวจพินบนบอร์ด แล้วค่อยเดินสายทีละเส้น

ESP32-WROOM-32
DevKitC V4 · 38 pins
คลิกพินบนบอร์ด · ใช้ Tab / Enter ได้
สีเหลือง: พินที่เลือกสีส้ม: มีผลตอนบูตสีฟ้า: รับเข้าเท่านั้น
3.3V คือระดับสัญญาณ

GPIO รับ 5V ไม่ได้ การเลี้ยงอุปกรณ์ด้วย 5V ไม่ได้แปลว่าต่อสัญญาณ 5V เข้า ESP32 ได้

เปลี่ยนหน้าที่ได้ แต่ไม่พร้อมกัน

I²C / SPI / UART / PWM / I²S ย้ายพินผ่านโค้ดได้ เลือกเฉพาะ GPIO ที่รองรับทิศทางนั้น และหนึ่งพินรับบทเดียวในขณะหนึ่ง

บอร์ดหน้าตาคล้าย พินอาจต่าง

ตัวอย่างยึด WROOM-32 แบบ 30 พิน ไม่ใช้ผัง S3 / C3 / WROVER ปะปน ตรวจสกรีนบอร์ดจริงเสมอ

ขา Flash และข้อควรรู้เพิ่มเติม

D0–D3, CMD และ CLK (GPIO6–11) อยู่บนหัวแถวของ V4 และต่อกับ SPI Flash ภายในโมดูล ให้เว้นไว้ · GPIO0 เป็น boot strapping และต่อกับปุ่ม BOOT แต่ไม่แยกออกหัวแถวในบอร์ด 30 พินนี้ · GPIO37/38 ไม่ได้ออกมาที่ WROOM-32 รุ่นนี้ · GPIO20/24/28–31 ไม่มีเป็น GPIO ใช้งานของ ESP32 รุ่นดั้งเดิม

Touch ใช้ touchRead เช่น GPIO32/33 ได้ แต่พิน Touch หลายขาเป็น strapping จึงเลือก 32/33 ก่อน · GPIO34–39 รับเข้าอย่างเดียว ไม่มี pull-up ภายใน · หลีกเลี่ยง ADC2 เมื่อใช้ Wi-Fi · ADC 12-bit ไม่เท่ากับความแม่นยำ 12-bit

ขา EN เป็น reset ไม่ใช่ GPIO; ชื่อ VP/VN บนบอร์ดคือ GPIO36/39 · พิน output ที่ไม่ติดข้อจำกัดอื่นใช้ PWM ได้ผ่าน LEDC โดยไม่จำเป็นต้องมีเครื่องหมาย ~ แบบ Arduino Uno
