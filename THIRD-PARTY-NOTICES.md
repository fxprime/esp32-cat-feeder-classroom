# Reference project

The Wiring Bench interaction pattern (lab → pinout → wiring → code) was informed by https://github.com/agharsallah/esp-labs-web at commit 6ab50779746290bd3767ca7816ff1ebeeb9120a3. That project targets ESP32-S3; the classic ESP32 pin data, Thai circuit recipes, SVG drawings and implementation here were newly authored. No firmware, components, images or source modules from the reference repository were copied. The reference's license is retained below for attribution.
